## About WeAreDevs PC

WeAreDevs PC is a Windows desktop application for Roblox script execution. Its design emphasizes quick access, a small footprint, and an uncomplicated workspace where users can load scripts, control executions, and manage their Lua workflow from one window.

In addition to direct execution, the app provides a broader script hub environment. Batch runs, automatic updates, a queue that survives restarts, and an integrated debugger are included to make Roblox scripting more structured on Windows 10 and Windows 11.

## Frequently Asked Questions

**Does the application support operating systems other than Windows?**  
No. Its intended desktop environment is Windows 10/11.

**Can it remain compatible when Roblox is updated?**  
The built-in update path is meant to help track current builds. However, actual compatibility may still be affected by changes made through Roblox updates.

**What does it provide beyond a standard Lua executor?**  
It combines ordinary script execution with a 500+ entry hub, sequential batch execution, debugger functionality, and queue data that persists between sessions.

**Could using a script executor create account-related risks?**  
Use the software at your own discretion, and observe the rules and terms governing your platform and environment.

**Where are queued scripts kept?**  
The application profile includes persistent queue storage, so queued entries may remain on the local computer after the app is closed.
